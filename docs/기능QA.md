# 기능 QA 현황표 (되는 것 / 안 되는 것)

> 기준일: 2026-07-18 (2026-07-03 대비 백엔드 블로커 대거 해소)
> **QA 담당자용** — 어떤 기능이 실제로 동작하는지, 안 되는지 화면 단위로 정리했습니다.
> 🔎 캘린더/활동결과/알림 등은 **저장공고·참여 데이터가 있는 계정**으로 확인해야 실데이터가 보입니다(데이터 없으면 예시 표시).

## 상태 표시

| 표시         | 의미                                          |
| ------------ | --------------------------------------------- |
| ✅ **됨**    | 실제로 정상 동작 (실데이터 연동)              |
| ⚠️ **부분**  | 화면은 뜨지만 임시데이터거나 일부만 동작      |
| ❌ **안 됨** | 백엔드 문제로 막혀 있음 (임시데이터로만 보임) |

> ⚠️/❌ 는 **프론트 문제가 아니라 백엔드 API 대기** 상태입니다. (하단 "안 되는 것" 참고)

| 회원가입(추가정보 입력)          | ✅ 됨 | 최초 가입 시 닉네임·직무 등 입력 |

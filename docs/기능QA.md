# 기능 QA 현황표 (되는 것 / 안 되는 것)

> 기준일: 2026-07-18 (api-spec 갱신 반영: **알림 개별삭제 API** · **저장공고 모집기간/저장일** 연동)
> **QA 담당자용** — 어떤 기능이 실제로 동작하는지, 안 되는지 화면 단위로 정리했습니다.

## 상태 표시

| 표시         | 의미                                          |
| ------------ | --------------------------------------------- |
| ✅ **됨**    | 실제로 정상 동작 (실데이터 연동)              |
| ⚠️ **부분**  | 화면은 뜨지만 임시데이터거나 일부만 동작      |
| ❌ **안 됨** | 백엔드 문제로 막혀 있음 (임시데이터로만 보임) |

> ⚠️/❌ 는 **프론트 문제가 아니라 백엔드 API 대기** 상태입니다. (하단 "안 되는 것" 참고)

## 8. 일정관리 (캘린더) — ⚠️ 대부분 임시데이터

| 기능                         | 상태     | QA 확인                                                                |
| ---------------------------- | -------- | ---------------------------------------------------------------------- |
| 일정 목록형 화면             | ⚠️ 부분  | 저장공고·**저장일·모집기간 실데이터 연동 완료**. 단 지원완료 여부만 활동결과 500으로 미반영 |
| 달력형(월별 이벤트 점)       | ⚠️ 부분 | 모집 시작/마감일 필드 생김 → **프론트 연결 예정**(현재 임시데이터)      |
| 날짜 클릭 시 그날 활동       | ❌ 안 됨 | 임시데이터 (날짜별 조회 API 없음)                                      |
| 활동 결과 탭(지원/합격/수료) | ❌ 안 됨 | **서버 오류(500)** 로 목록 안 옴                                       |
| 지원완료 토글(지원여부 변경) | ⚠️ 부분  | 활동결과 화면엔 토글 있으나 위 500 때문에 실제 데이터로 확인 불가      |

---

## ❌ 지금 "안 되는 것" (백엔드 API 대기 — 프론트는 준비됨)

1. **일정관리 > 활동 결과 탭** — 서버 오류(500)로 목록 조회 불가
2. **일정관리 날짜별 활동(날짜 클릭)** — 날짜별 조회 API 부재로 임시데이터
3. **알림 읽음 표시 / 실시간 알림** — 관련 API 미연결
4. **지원완료(지원여부) 토글의 실동작** — 위 활동결과 500이 풀려야 확인 가능

## ⚠️ "부분만 되는 것" (동작하나 임시/우회)

- 검색기록 전체삭제(개별삭제로 우회) · 내 작성글 빈 상태 임시데이터 · 마이페이지 관심직무 예시값 · 일정 목록 **지원완료 여부**(활동결과 500 대기) · 일정 달력형(모집기간 필드 생김, 프론트 연결 예정)

## ✅ 요약

- **로그인·회원·활동·검색·리뷰·아카이브·북마크**: 정상 동작 ✅
- **알림 일부(읽음/실시간)·일정관리(캘린더)**: 백엔드 대기로 임시데이터/막힘 ❌
- QA 시 위 "안 되는 것"은 **버그가 아니라 백엔드 미완**임을 참고해주세요.
